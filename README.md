# CMO_TW

《Command: Modern Operations（現代行動：指揮）》正體中文化修補程式。

## 下載

前往[Releases](https://github.com/NekoDream/CMO_TW/releases/)下載最新建置檔。

## 版本與適配

- **適配的遊戲內部版本：`1900.24`** —— 即遊戲標題裏的 `Command: Modern Operations v1.10 - Build 1900.24`。
- **遊戲每次更新（構建號變化）都可能致使修補程式失效** —— 請下載使用最新建置檔。

## 修改說明
- **全數校訂至繁體中文：** 將原有簡體中文轉換至繁體中文，專業詞彙之翻譯參照國防部《新編國軍簡明美華軍語辭典（114年版）》進行校正。
- **替換矮化我國格之用語：** 我國機關及軍隊由「中國台灣」、「台軍」或「國民黨軍」一律規範為「中華民國 / 中華民國（台灣）/ 中華民國國軍 / 國軍 / 國軍陸軍」等；中共政權與軍隊不使用「中國」、「匪軍」或「解放軍」，按現況翻譯為「中共國 / 中華人民共和國 / 共軍 / 中共陸軍」等。
